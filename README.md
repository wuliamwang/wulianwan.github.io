# 禾语 · 智慧农业环境监测与灌溉决策平台

> 《物联网 Web 开发技术》期末考核（答辩）作品
> 山东华宇工学院 · 信息工程学院 · 物联网工程 2024 级 2402 班
> 2026—2027 学年第一学期
>
> 在线预览：https://wulianwangiot.github.io/

一个纯前端、零依赖安装、可离线双击打开的智慧农业管理平台：围绕「环境监测 → 灌溉决策 → 设备执行 → 数据分析」的完整业务闭环，用 9 个页面把物联网数据在浏览器端的采集、呈现、交互与决策过程完整演示出来。

---

## 一、如何运行

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| 最简单 | 双击 `index.html` | 所有依赖都在本地，无需联网、无需安装 |
| 推荐 | VS Code + Live Server 打开 `index.html` | 与实验课环境一致，热更新更方便 |
| 固定主题 | 访问 `index.html?theme=light` 或 `?theme=dark` | 截图 / 演示时锁定主题；该偏好会被记住，跳转其它页面仍生效 |

> 演示数据由浏览器内的「IoT 中间件模拟器」生成，固定随机种子 + 平滑漂移：刷新页面数值稳定，停留页面时又会持续小幅变化。

## 三、技术栈

| 层次 | 技术 | 用法说明 |
| --- | --- | --- |
| 结构 | **HTML5** | 语义化标签、`<svg><symbol>` 图标精灵、`<table>` 台账、`<form>` 校验、ARIA 属性 |
| 样式 | **CSS3** | 自定义属性（深浅双主题）、Grid + Flex、`@keyframes`、`clamp()`、`backdrop-filter`、`color-mix()` 降级 |
| 交互 | **JavaScript (ES5+)** | IIFE 模块、发布订阅、IntersectionObserver、requestAnimationFrame、Blob 下载、localStorage |

| 库 | **jQuery 3.7** | DOM 选择、事件委托、`$.fn` 插件调用（nstSlider）、Bootstrap 依赖 |
| 图表 | **Highcharts 11.4** | 面积图 / 折线图 / 柱状图 / 堆叠柱 / 环形图 / 组合双轴；统一封装成 `AgriCharts` 工厂 |

## 五、架构：数据是怎么流动的

```
   ┌──────────────────────────────────────────────────────────────┐
   │  data.js        种子数据（地块 / 设备 / 传感器 / 告警 / 气象） │
   └───────────────┬──────────────────────────────────────────────┘
                   │ 深拷贝
   ┌───────────────▼──────────────────────────────────────────────┐
   │  iot-middleware.js                                           │
   │  · 设备影子（devices）                                        │
   │  · 发布订阅：telemetry / device / alarm / irrigation / log    │
   │  · 3 秒采集循环，平滑漂移，边界收敛                            │
   │  · 业务算法：computeDecision() 水量平衡模型                    │
   │  · 指令下发：setDevice / executeIrrigation（带进度回调）        │
   │  · 设置持久化：localStorage                                   │
   └───────────────┬──────────────────────────────────────────────┘
                   │ 订阅
   ┌───────────────▼──────────────────────────────────────────────┐
   │  页面脚本（js/pages/*.js）                                     │
   │  只依赖 AgriIoT 的公开 API 渲染，不直接操作定时器              │
   └───────────────┬──────────────────────────────────────────────┘
                   │
   ┌───────────────▼──────────────────────────────────────────────┐
   │  charts.js / app.js  统一图表主题、动效、提示条、主题切换      │
   └──────────────────────────────────────────────────────────────┘
```

**为什么这样设计？** 真实项目中这一层是 MQTT Broker + 规则引擎 + 时序数据库。把传输层抽象成 `AgriIoT`，页面代码只订阅事件；将来换成 WebSocket 或 MQTT.js，页面脚本一行都不用改。答辩时这一点可以直接讲。

### 灌溉决策算法（简化水量平衡模型）

```
缺水量 V = (目标含水率 − 当前含水率) × 面积 × 单位系数 0.15 × 作物系数 Kc
再按未来 24h 降雨概率折减（≥60% 折减 40%，≥30% 折减 15%）
并叠加参考蒸散量 ET₀ 的补充项
→ 得到建议水量、预计时长、紧迫度评分（0–100）
```

各作物系数：番茄 1.06、黄瓜 1.00、小麦 0.82、草莓 0.90。

## 七、代码约定

- **命名**：CSS 用 BEM 思路（`.card__title`、`.device__status`），JS 用 `小驼峰`，文件用 `kebab-case`；
- **注释**：每个 JS 模块有文件头注释说明职责，关键算法（决策模型、序列生成、图表工厂）有行内说明；CSS 按「令牌 / 壳层 / 组件 / 页面」分区并标注；
- **状态**：所有实时数据只在 `iot-middleware.js` 内变更，页面只渲染不篡改；
- **配置**：颜色、圆角、阴影、缓动全部收敛到 `:root` 变量，换肤只改一处；
- **构建**：`tools/build.mjs` 单文件、零依赖，保证 9 个页面壳层一致。
